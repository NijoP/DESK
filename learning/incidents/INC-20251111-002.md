# INC-20251111-002

- **Subsystem:** easyeda-integration / pcb-panelisation
- **Severity:** HIGH

---

## Context
**What were you trying to accomplish?**
Adding manufacturing features to the panel PCB: panel outline (board outline layer 11), fiducial marks, tooling holes, and panel identification text. The panel was created as a PCB document (via `dmt_Pcb.createPcb()`) rather than a Panel document.

---

## Expected Behaviour
**What should have happened?**
`eda.pcb_PrimitiveRegion.create(11, poly, [2], "Panel Outline", 10, false)` should create a board outline region on layer 11 (BOARD_OUTLINE) for the panel boundary.

---

## Actual Behaviour
**What actually happened?**
```
错误：无法创建区域图元，可能是传入的参数不正确。
```
(Translation: "Unable to create region primitive, possibly incorrect parameters passed.")

The same code worked when executed on a Panel document but failed on a PCB document.

---

## Error Evidence
**Failed on PCB document (type=3):**
```javascript
const poly = eda.pcb_MathPolygon.createPolygon(["R", 0, 0, W, H, 0, 0]);
const outline = await eda.pcb_PrimitiveRegion.create(11, poly, [2], "Panel Outline", 10, false);
```

**Succeeded on Panel document (type=26):**
Same exact code worked when the active document was a Panel.

---

## Root Cause Analysis

### Identified Cause
**PCB documents and Panel documents have different primitive creation capabilities.** The `pcb_PrimitiveRegion.create()` API behaves differently depending on the active document type. On PCB documents, board outline creation may be restricted or require different parameters. On Panel documents, board outline creation is the primary operation.

### Classification
- [x] Incorrect assumption (assumed PCB and Panel docs support same primitives)
- [x] Missing documentation (document type restrictions not documented)
- [ ] API incompatibility
- [ ] Implementation defect
- [ ] Engineering mistake
- [ ] Validation failure
- [ ] Environmental problem
- [ ] Resource/performance limitation
- [ ] Unknown cause

### Why the Original Approach Failed
Created the panel as a PCB document (`dmt_Pcb.createPcb()`) instead of a Panel document (`dmt_Panel.createPanel()`), then tried to use PCB primitive APIs that don't support board outline creation on PCB docs.

---

## Recovery

### Attempts Made
| Attempt | Action | Result |
|---------|--------|--------|
| 1 | Create panel as PCB, add outline | FAILED |
| 2 | Test region creation on PCB doc | FAILED |
| 3 | Test region creation on Panel doc | SUCCESS |
| 4 | Switch to `dmt_Panel.createPanel()` | SUCCESS |

### Successful Solution
**Use `dmt_Panel.createPanel()` to create the panel document**, not `dmt_Pcb.createPcb()`. Panel documents natively support board outline creation on layer 11.

### Verification Evidence
```javascript
// This works on Panel document:
const panelUuid = await eda.dmt_Panel.createPanel();
await eda.dmt_EditorControl.openDocument(panelUuid);
const poly = eda.pcb_MathPolygon.createPolygon(["R", 0, 0, W, H, 0, 0]);
const outline = await eda.pcb_PrimitiveRegion.create(11, poly, [2], "Panel Outline", 10, false);
// Returns: {ok: true, outline: true}
```

## Engineering Learning

### What This Failure Taught You
EasyEDA document types (PCB, Schematic, Panel) have different API capabilities. Primitive creation APIs are document-type aware. Assuming uniform API across document types is incorrect.

### Why Original Approach Failed
Created wrong document type for the task. Panel outlines are first-class concepts in Panel documents, not PCB documents.

### What Should Have Been Done Differently
Check document type capabilities before choosing creation API. Use `dmt_Panel.createPanel()` for manufacturing panels.

### Missing Information
EasyEDA API documentation doesn't specify which primitives are valid per document type.

### Early Warning Signs
- "Unable to create region primitive" error
- Working on PCB doc but need panel features
- Document type mismatch for intended operation

### Future Prevention
**Rule:** Match document type to task: Panel doc for panelisation, PCB doc for single board design, Schematic doc for schematics.

---

## Prevention Strategy

### Preventive Rule/Procedure
```
DOCUMENT_TYPE_RULES:
1. Panelisation → dmt_Panel.createPanel()
2. Single PCB design → dmt_Pcb.createPcb()
3. Schematic → dmt_Schematic.createSchematic()
4. Verify document type before primitive creation
5. Test primitive creation on target doc type first
```

### Implementation in DESK
Updated `PanelisationEngine._create_panel_document()` to use `dmt_Panel.createPanel()` instead of `dmt_Pcb.createPcb()`.

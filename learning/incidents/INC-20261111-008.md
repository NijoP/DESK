# INC-20261111-008

## Metadata
- **Date/Time:** 2026-11-11 22:20 IST
- **Project/Task:** WATCH rev B — board outline for DSN export
- **Subsystem:** EasyEDA Pro API: pcb_PrimitivePolyline.create / pcb_ManufactureData.getDsnFile
- **Severity:** HIGH (EasyEDA Pro froze twice; required force-close)
- **Status:** OPEN (workaround in progress)

## What happened
1. `getDsnFile()` returned `undefined` for a board whose outline was 36 separate `pcb_PrimitiveLine` segments on layer 11.
   The GUI export (File > Export > DSN) showed the real reason: "board outline missing". The DSN exporter needs ONE closed
   outline primitive; separate segments are not recognised, even when the loop is closed within 0.5 mil.
2. `pcb_PrimitivePolyline.create("", 11, eda.pcb_MathPolygon.createPolygon(<36 flat vertices>), 8)` froze the EasyEDA
   renderer (two out of two attempts, including once with nothing else in the request). The gateway kept reporting the
   window as connected; every later request timed out. Only Task Manager could end the process.
   `createPolygon(["R", x, yTop, w, h, 0, 0])` -> polyline is created instantly; `["R", ..., rx, ry]` is created instantly
   but `getPrimitivesBBox` reports a wrong box for it (arc bbox is unreliable, see INC notes in 00_CHECKPOINTS).

## Lesson
- Draw board outlines as ONE polyline primitive on layer 11 (an `"R"` polygon, radii allowed), never as line segments.
- Never pass long flat vertex lists to `pcb_PrimitivePolyline.create`; it can hang the editor. Prefer `"R"` polygons.
- Never chain a `getDsnFile` export into the same request as a mutation; keep each step its own short request so a hang is
  attributable and the saved state is known.
- Verify outline geometry from the exported DSN `(boundary ...)` path, not from `getPrimitivesBBox`.

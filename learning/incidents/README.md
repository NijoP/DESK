# Incidents Directory

Contains individual incident reports following the `INCIDENT_TEMPLATE.md` format.

## Naming Convention
`INC-YYYYMMDD-NNN.md`

## Index
See `../index/INCIDENT_INDEX.md` for searchable index.

## Guidelines
- One file per significant incident
- Include root cause analysis
- Document recovery attempts
- Extract reusable lessons
- Cross-reference related incidents

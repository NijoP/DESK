## What happened
1. `pcb_Document.importChanges()` returns `true` but only opens the Import Changes dialog; nothing is applied until the Captain clicks Apply. Second trap: the dialog lists NOTHING unless the schematic document was saved first (`sch_Document.save()` after build.py). Fix: save schematic → trigger importChanges → Captain applies → read components back.
2. `pcb_Drc.overwriteCurrentRuleConfiguration()` and `saveRuleConfiguration()` return `undefined`/`false` in EasyEDA Pro 3.2.149 with the API gateway: rule tables cannot be written by API. `overwriteNetRules()` DOES work (per-net rule binding). Fix: Captain enters the tables in Design → Design Rules; agent verifies via `getCurrentRuleConfiguration()` + RULE / RULE_SELECTOR records in `getDocumentSource()` + a negative DRC test (temporary violating track).
3. The Safe-Spacing "Hole" row applies to via holes as well as mounting holes → a 2.5 mm Hole row makes every via near a track a violation. Mounting holes drawn as pads with ring = hole are "TH Pad" objects → use the TH Pad row/column for the 2.5 mm keep-away and leave the Hole row at 0.3 mm.
4. Giving mounting-hole pads dummy nets to bind a per-net rule fails: single-pad nets raise Connection Errors and adjacent holes of different nets violate each other.
5. `pcb_PrimitiveVia.create(net,x,y,holeDiameter,diameter)` — argument order is hole first; swapping gives a "Via Size" physical error.
6. `lib_Device.search` finds parts by exact MPN far better than by description keywords; resistor MPN strings contain "Ω" and "±" (e.g. `MOF2WS-47KΩ±5% T`) and must be passed verbatim.
7. Window IDs rotate on reconnect mid-session; `light/tools/lightwin.py` resolves the window by project uuid before every call and skips the sensor-patch window.

## Preventive lessons
- Schematic → PCB sync = save schematic, trigger dialog, Captain applies, API readback. Never assume `true` means applied.
- DRC rule tables = dialog + readback + negative test. Per-net binding by API is fine.
- Mains boards: protect mounting holes via the TH Pad row, bind HV nets to a dedicated 3 mm table.
- Series diodes in a dropper always see full mains across their own pads → SMA (2.4 mm gap) cannot meet 3 mm; use DO-41 or a wider package.

# Sessions Directory

Contains session-level engineering logs for each DESK execution session.

## Naming Convention
`SESSION-YYYYMMDD-HHMM-project-description.md`

## Structure
Each session log records:
- Start/end time
- Project/task
- Operations attempted
- Results (success/failure/unexpected)
- Incidents encountered (linked to incident reports)
- Decisions made
- Outstanding issues

## Guidelines
- Log in real-time during execution
- Record intended operation before executing
- Note unexpected behaviour immediately
- Link to incident reports when created
- Summary at session end

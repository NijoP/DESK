## The Lesson

### Principle
The EasyEDA bridge server has undocumented resource limits (execution time, memory, payload size) that cause non-deterministic 500 errors when exceeded. Atomic operations (<100 lines, single API domain, <5KB return) succeed reliably.

### Why It Matters
Monolithic scripts appear to work in browser console but fail in bridge server due to different execution context (server-side V8 isolate with constraints). Non-deterministic failures waste debugging time and compromise engineering reliability.

### Correct Behaviour
```python
# GOOD: 8 atomic calls
components = executor(script_components)      # ~30 lines, returns components
tracks = executor(script_tracks)              # ~20 lines, returns tracks
vias = executor(script_vias)                  # ~20 lines, returns vias
zones = executor(script_zones)                # ~20 lines, returns zones
poured = executor(script_poured)              # ~15 lines, returns poured
outline = executor(script_outline)            # ~25 lines, returns outline
nets = executor(script_nets)                  # ~10 lines, returns nets
```

### Incorrect Behaviour (Anti-pattern)
```python
# BAD: 1 monolithic call (500+ lines)
everything = executor(script_everything)      # 500+ lines, returns everything
# → Non-deterministic 500 errors
```

---

## Practical Application

### When to Apply
- Any EasyEDA bridge script >100 lines
- Any script using multiple `getAll()` + `map()` operations
- Any script returning >5KB JSON
- Any long-running extraction/inspection operation

### How to Apply
1. Identify distinct API domains in the script
2. Split into one call per domain
3. Add 15s timeout per call
4. Validate each result before composing
5. Aggregate in Python, not JavaScript

### Verification
- Each call returns `ok: true` consistently
- Total execution time < sum of individual timeouts
- No 500 errors across 10+ consecutive runs

---

## Prevention Rule

### Rule Statement
**BRIDGE_ATOMIC_OPERATIONS:** Every bridge execution must target a single primitive type or API domain. Maximum 100 lines, 15s timeout, 5KB return payload.

### Implementation in DESK
- `desk.adapters.easyeda_pcb_adapter.EasyEDAPcbAdapter.build_batch_readback_script()` → split into multiple scripts
- `desk.panelisation.engine.PanelisationEngine.extract_pcb_geometry()` → 8 separate calls
- All new bridge scripts must pass atomicity review

# Lessons Directory

Contains reusable engineering lessons extracted from incidents, following the `LESSON_TEMPLATE.md` format.

## Naming Convention
`LSN-YYYYMMDD-NNN.md`

## Index
See `../index/LESSON_INDEX.md` for searchable index.

## Guidelines
- One file per reusable engineering principle
- Link to originating incident(s)
- State confidence level honestly
- Include prevention rule for DESK implementation
- Mark superseded lessons, don't delete

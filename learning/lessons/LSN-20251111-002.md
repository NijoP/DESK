## Title
Match Document Type to Task: Panel Documents for Panelisation

## Summary

## The Lesson

### Principle
`pcb_PrimitiveRegion.create(layer=11, ...)` for board outlines only works on Panel documents, not PCB documents. PCB documents restrict board outline creation because outlines are managed differently (single board vs multi-board panel).

### Why It Matters
Using the wrong document type causes "unable to create region primitive" errors that appear to be parameter problems but are actually document-type restrictions. This wastes debugging time investigating parameters that are actually correct.

### Correct Behaviour
```javascript
// Panelisation → Panel document
const panelUuid = await eda.dmt_Panel.createPanel();
await eda.dmt_EditorControl.openDocument(panelUuid);
const outline = await eda.pcb_PrimitiveRegion.create(11, poly, [2], "Panel Outline", 10, false);
// SUCCESS
```

### Incorrect Behaviour (Anti-pattern)
```javascript
// Panelisation → PCB document (WRONG)
const pcbUuid = await eda.dmt_Pcb.createPcb();
await eda.dmt_EditorControl.openDocument(pcbUuid);
const outline = await eda.pcb_PrimitiveRegion.create(11, poly, [2], "Panel Outline", 10, false);
// FAILS: "Unable to create region primitive"
```

## Practical Application

### When to Apply
- Creating manufacturing panels
- Adding board outlines
- Multi-board array generation
- Any operation requiring panel-level primitives

### How to Apply
```python
def create_panel_document(name: str) -> str:
    """Create panel document for panelisation tasks."""
    script = f'''
    const panelUuid = await eda.dmt_Panel.createPanel();
    await new Promise(r => setTimeout(r, 1500));
    await eda.dmt_Panel.modifyPanelName(panelUuid, "{name}");
    return {{ok: true, panel_uuid: panelUuid}};
    '''
    return executor(script)["panel_uuid"]

# NOT:
# def create_panel_document(name: str) -> str:
#     # WRONG - creates PCB, not Panel
#     script = f'const pcbUuid = await eda.dmt_Pcb.createPcb(); ...'
```

### Verification
- `dmt_Panel.createPanel()` returns valid UUID
- `pcb_PrimitiveRegion.create(layer=11, ...)` succeeds
- Panel document type = 26 (not 3 for PCB)

---

## Prevention Rule

### Rule Statement
**DOCUMENT_TYPE_MATCHING:** Match document creation API to task domain:
- Panelisation/manufacturing panels → `dmt_Panel.createPanel()`
- Single PCB design → `dmt_Pcb.createPcb()`
- Schematic design → `dmt_Schematic.createSchematic()`

### Implementation in DESK
- `desk.panelisation.engine.PanelisationEngine._create_panel_document()` uses `dmt_Panel.createPanel()`
- Add document type validation to adapter layer
- Unit test for each document type's primitive capabilities

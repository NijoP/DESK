# Playbooks Directory

Contains recovery and prevention procedures for known failure patterns.

## Structure
Each playbook documents a complete procedure for handling a specific failure class.

## Naming Convention
`PB-YYYYMMDD-NNN-descriptive-name.md`

## Index
See `../index/KNOWN_FAILURES.md` for failure pattern references.

## Guidelines
- Step-by-step recovery procedures
- Decision points with criteria
- Verification steps
- Escalation paths
